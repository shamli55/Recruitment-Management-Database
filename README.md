# Recruitment Management Database – Snowflake

A **Recruitment Management Database** built using **Snowflake SQL** to manage and analyze the complete recruitment process, including candidates, jobs, recruiters, applications, interviews, and hiring outcomes.

### 🔹 Project Overview

This project demonstrates how a recruitment organization can use a centralized cloud data warehouse to store, manage, and analyze recruitment data efficiently. The database is designed with multiple related tables and SQL queries to generate meaningful recruitment insights.

### 🔹 Technologies Used

* **Snowflake**
* **SQL**
* Database Design & Relationships
* Joins & Subqueries
* CTEs
* Window Functions
* Views
* Stored Procedures
* Aggregate Functions

### 🔹 Key Features

* Candidate and recruiter management
* Job posting and job application tracking
* Interview scheduling and tracking
* Candidate selection and rejection analysis
* Recruitment performance analysis
* Department and job-role based reporting
* Identification of top-performing recruiters
* Candidate application and hiring status tracking

### 🔹 SQL Concepts Implemented

* DDL & DML
* Primary Keys & Foreign Keys
* INNER JOIN, LEFT JOIN and SELF JOIN
* GROUP BY & HAVING
* Subqueries
* CTEs
* CASE statements
* Aggregate Functions
* Window Functions such as `RANK()`, `DENSE_RANK()` and `ROW_NUMBER()`
* Views
* Stored Procedures

### 🔹 Example Analysis

The project can answer questions such as:

* Which job roles receive the highest number of applications?
* What is the candidate-to-hire conversion rate?
* Which recruiters handle the most successful hires?
* What is the average time taken to hire a candidate?
* Which departments have the highest recruitment demand?
* What are the top candidates based on interview performance?

### 🔹 Project Outcome

The project provides a structured **recruitment data management and analytics solution** using Snowflake, helping organizations track recruitment activities and derive insights from candidate and hiring data.
